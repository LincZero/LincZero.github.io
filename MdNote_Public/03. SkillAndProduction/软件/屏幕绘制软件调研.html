屏幕绘制软件调研

背景

像 snipaste pixpin 等软件可以进行先截图贴图，再绘制。
但我有时想要不截图直接在屏幕上进行绘制标记，否则比较麻烦。
且还要要求支持：

  • 多种画笔、擦除、清空等操作。
  • 并且绘制过程可以中断，在依然显示标记的前提下，正常点击屏幕上的内容，然后随时进行继续绘制。

请帮我调研相关的软件

调研 - 总结

这里先进行了 GPT 和搜索调研，并在这里统一比较总结。关于从 GPT 和文章调研的记录可以见后文。

主要是以下三个：

  • Epic Pen
    不开源
    分免费和 pro 版。其中 gInk
  • gInk
    https://github.com/geovens/gInk ⭐2.5k, last year
    受 Epic Pen 启发
  • ppInk
    https://github.com/pubpub-zz/ppInk ⭐1.2k, 2 week sago
    注意，这是 gInk 的一个分支。维护更活跃，功能更多

使用

ppInk 踩坑:

一是要运行那个脚本替换 windows.ink
二是注意不要用自带解压缩 https://github.com/pubpub-zz/ppInk/issues/357

使用:

ctrl+alt+g 召唤画笔以及隐藏画笔，不要用 ESC。
ESC除了会消除画笔痕迹和退出画笔状态外，还会重置当前的工具属性 (如画笔颜色和粗细)

调研 by 文章

ppInk、gInk：免費、開源的螢幕標註＋電子白板工具，簡報、教學錄影必備

Epic Pen 的最佳替代品是什么？ : r/software

调研 by Claude Sonnet 4.6

你的需求核心是：透明覆盖层绘制（不截图）+ 穿透点击（可交互屏幕）+ 可随时继续绘制，这比普通截图贴图工具要求更高。以下是调研结果：

✅ 完全符合需求的软件

1. Ink2Go (Windows/Mac)

  • 直接在屏幕上绘制，不截图
  • 支持多种画笔、荧光笔、橡皮擦
  • 可切换"鼠标模式"穿透点击，再切回绘制模式，标记保留
  • 适合演示、教学场景
  • 💰 付费软件

2. Epic Pen (Windows) ⭐ 推荐

  • 专为"屏幕上直接绘制"设计
  • 支持画笔、荧光笔、橡皮擦、清空
  • 有专门的"穿透模式"按钮（托盘/快捷键切换），切换后可正常操作屏幕，标记依然保留
  • 免费版功能基本够用，Pro 版更完整
  • 🔗 https://epicpen.com

3. gInk (Windows) ⭐ 开源免费推荐

  • 开源免费，轻量
  • 支持多种颜色、粗细、橡皮擦
  • 支持暂停绘制（屏幕穿透）后恢复
  • 🔗 https://github.com/geovens/gInk

4. Annotate Screen / ScreenMarker (Windows)

  • 轻量屏幕标注工具
  • 基本满足需求，但穿透交互能力较弱

Epic Pen 和 gInk 最符合你描述的工作流：绘制 → 切换穿透点击屏幕 → 再切回继续绘制，标记全程保留。

调研 by Deepseek20260602

你提到的“直接画在屏幕上，还能随时点击屏幕内容”这种不中断工作流的标注体验，确实是追求高效的核心需求。我整理了一些能满足你要求的工具，它们大多是免费的，你可以根据自己的具体场景来选择。

✍️ 核心功能概述

你所描述的“直接在屏幕上绘制，且能与背景内容交互”的功能，通常被称为 屏幕标注 或 桌面画笔。这类工具通过在屏幕上创建透明或半透明的浮层，让你能随时绘制，同时点击穿透（Click-Through） 功能又允许你暂时绕过这个图层，直接操作背后的应用程序。

📋 按平台的软件方案对比

为了方便你选择，我根据不同的操作系统，将主流的工具整理如下：

💻 Windows 平台

这是该类别工具最丰富的平台，选择很多。

工具名称核心特点点击穿透成本额外优势
gInk轻量、开源、支持数位板压感。界面极简，内置 5 个预设画笔，并支持“鼠标穿透模式”。✅ 支持免费资源占用极低，拖盘图标操作，非常符合你的“随时中断，随时画”的需求。
Pointofix经典的“屏幕神奇作图工具”，功能非常强大。将整个屏幕变成电子白板，提供丰富的线条、箭头、文字、高亮等工具。✅ 支持 (通过快捷键切换)免费软件体积小（不足1MB），支持热键（如F5启动，Ctrl+Z撤销），十分稳定。
ZoomIt微软官方出品，稳定可靠。集成微软 Sysinternals 套件，核心是屏幕放大功能，但也支持“不缩放直接绘制”（draw-without-zoom）。✅ 支持 (停止绘制后)免费非常适合演示场景，能与演示计时器等功能无缝结合。
LiveDraw专注于“实时”绘制的工具。采用透明背景绘制技术，在任何界面（包括视频）上流畅标注，支持压感和无限撤销/重做。✅ 支持 (可临时禁用绘图)免费界面现代，专为解决动态内容标记而设计，体验流畅。
Epic Pen一款流行、商业化的屏幕标注软件。界面美观，工具齐全（画笔、高亮、形状），支持多显示器，稳定性高，广受好评。✅ 支持 (可隐藏所有标注)免费版/付费版基础功能免费，付费版解锁更多工具和自定义选项。
ppInk免费开源的标注工具。支持自定义快捷键快速呼出面板，内置丰富的贴纸库，适合需要快速切换工具的场景。信息缺失免费适合需要多人协作标注的团队，支持不同成员使用专属颜色进行区分。
PaintoWindows 应用商店应用。特色是支持“真实橡皮擦”，可以像橡皮一样部分擦除线条，而不仅仅是整条删除。全局快捷键支持完善。✅ 支持 (切换至“电脑模式”)可能有免费版/付费版性能优秀，采用 GPU 加速，在 4K 分辨率下也能保持流畅。
On Screen Drawing ToolAutoHotkey 社区的高自由度作品。完全开源，适合有定制需求的用户。提供6 种绘图工具，支持自定义颜色、线宽和透明度。✅ 支持 (通过浮动面板切换)免费脚本爱好者可以自由修改，满足个性化需求。
CapyCursor免费且轻量，除了屏幕绘制，还提供光标高亮、缩放和聚光灯等视觉增强功能，特别适合在线教学和演示时引导观众注意力。信息缺失免费功能定位非常独特，专注于视觉沟通。
好哈/家软屏幕画笔国产轻量级工具，界面和功能接近 Pointofix。提供画笔、箭头、矩形等常用工具，支持透明度调节，还内置了放大镜功能。信息缺失可能是免费软件对国内用户友好，适合快速上手。

🍎 macOS 平台

针对 macOS 用户的解决方案相对较少，但也有一些不错的选择。

工具名称核心特点点击穿透成本
SketchScreen跨平台（Mac & Win）工具，采用 Excalidraw 渲染引擎，注释效果自然。通过付费订阅模式提供更高质量的服务。信息缺失付费订阅 (约$15/年)
Fastshot跨平台工具（Win & Mac），核心是截图和标注，但也提供了 Screen Pen（屏幕画笔） 功能，可在任意位置即时涂鸦。信息缺失可能是免费/付费模式

🐧 Linux 平台

对于 Linux 用户，也有一些不错的开源选项。

工具名称核心特点点击穿透成本
Gromit-MPXLinux 桌面环境下的经典屏幕标注工具。可运行于后台，按需激活（如 F9 键），让你在所有正在运行的应用上绘制高亮。✅ 支持 (可隐藏/显示窗口)免费
SketchScreen(同上) 跨平台工具，也支持 Linux，但正式支持可能稍晚。信息缺失付费订阅

💡 总结与选择建议

根据你的核心需求——直接在屏幕上绘制、支持多种画笔、可随时中断继续，gInk 和 Pointofix 是最符合的免费选择，一个极简，一个强大。如果你想追求更现代的界面和功能，LiveDraw 和 Epic Pen 值得一试。

  • 追求极简与高效：选 gInk，它的“鼠标穿透模式”完美契合你的“中断绘制”需求。
  • 想要功能全面：选 Pointofix，它是一款近乎完美的“电子白板”，功能极为丰富。
  • 偏爱现代设计与流畅体验：选 LiveDraw 或 Epic Pen，它们都是口碑很好的现代屏幕标注工具。
  • Linux用户：首选 Gromit-MPX，它是该平台上久经考验的标杆。
