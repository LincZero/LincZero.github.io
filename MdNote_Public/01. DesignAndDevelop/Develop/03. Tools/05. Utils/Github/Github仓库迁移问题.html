仓库迁移问题

仓库迁移问题

流程

  1. 进入对应仓库
  2. 点Setting -> 拉到最下面 -> DangerZone里的Transfer ownership （危险区域中的转移所有权） -> Transfer
  3. 确认完成即可

注意事项

  • Star数、commits历史、Issues 是否会被改变？
    • 否
  • 是否能让原来的url自动跳转到新的url？
    • 网上似乎有说需要另行设置的（修改 .gitattributes 文件）
    • 但我实测了一下，发现会自动跳转
